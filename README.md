# 💱 Currency Converter

A simple and responsive **Currency Converter Web App** built using **HTML, CSS, and JavaScript**. It allows users to convert currencies in real-time using exchange rate APIs.

---

## 🚀 Features

- 🌍 Convert between multiple international currencies  
- 🔄 Real-time exchange rate calculation  
- 📱 Responsive design (works on mobile & desktop)  
- ⚡ Fast and lightweight  
- 🎨 Clean and simple user interface  

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – Logic and API handling  
- **Exchange Rate API** – Fetch live currency data
